# ChatSQL — AI-Powered SQL Assistant

ChatSQL is an AI-powered application that allows users to interact with databases using natural language. Instead of writing SQL queries manually, users can ask questions in plain English and receive answers generated by an LLM-powered SQL agent.

Built with **Python, Streamlit, LangChain, and Groq**, ChatSQL simplifies database querying and makes data analysis more accessible.

## Features

- **Natural Language to SQL:** Ask questions about your database in plain English.
- **AI-Powered SQL Agent:** Uses LangChain to interpret questions and interact with databases.
- **Multiple Database Support:** Supports SQLite and MySQL.
- **Interactive Web Interface:** Built with Streamlit for a simple, user-friendly experience.
- **LLM Integration:** Uses Groq-hosted language models for fast inference.
- **Database Querying:** Retrieves information from connected databases based on user questions.
- **Secure Configuration:** Store API keys and database credentials in environment variables.

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/ChatSQL.git
cd ChatSQL
```

Replace `YOUR_USERNAME` with your GitHub username.

### 2. Create a Virtual Environment

Using Python's built-in `venv`:

**Windows (PowerShell)**

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**Linux / macOS**

```bash
python -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure Environment Variables

Create a `.env` file in the project root:

```env
GROQ_API_KEY=your_groq_api_key
```

Add any additional database credentials required by your application. Obtain your Groq API key from the [Groq Console](https://console.groq.com/).

**Security:** Never commit your actual API key, passwords, or other secrets to GitHub.

### 5. Configure the Database

**SQLite:** Place your SQLite database file in the expected project location and ensure the application points to the correct path.

**MySQL:** Ensure MySQL Server is running, create or select an existing database, and provide the required connection credentials through your application's configuration.

### 6. Run the Application

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal, usually:

```text
http://localhost:8501
```

## How It Works

1. The user selects a database type and supplies the required connection details.
2. The application establishes a connection using SQLAlchemy and LangChain's `SQLDatabase`.
3. The user asks a question in natural language.
4. The language model interprets the question and the SQL agent determines the appropriate database operation.
5. The application executes the generated query and presents the result in the Streamlit interface.

## Example Queries

You can ask questions such as:

- Show all students in the database.
- How many students are present in each department?
- Find the top five students based on marks.
- Calculate the average marks of students.
- Show students whose marks are greater than 80.

*These examples assume the connected database contains a student table with the relevant columns.*

## Security Considerations

- Keep API keys and database passwords in environment variables.
- Use read-only database permissions whenever possible.
- Validate generated SQL and restrict potentially destructive operations.
- Avoid connecting the application to production databases without appropriate access controls.
- Do not upload private datasets or database credentials to a public repository.
